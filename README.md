## ✨ About The Project

A modern cinematic developer portfolio built with advanced frontend animations, immersive UI interactions, smooth scrolling, and high-performance 3D experiences.

This portfolio is designed to feel like a movie experience instead of a traditional website.

---

## 🚀 Features

* ⚡ Smooth cinematic animations
* 🎥 Advanced motion effects
* 🌌 3D interactions and immersive UI
* 📱 Fully responsive design
* 🎨 Modern glassmorphism aesthetics
* 🖱️ Smooth scrolling experience
* 🔥 Optimized performance
* 🌙 Dark modern interface

---

## 🛠️ Tech Stack

### Frontend

* Next.js
* React.js
* TypeScript
* Tailwind CSS

### Animation & 3D

* Framer Motion
* GSAP
* Three.js
* Lenis Smooth Scroll
